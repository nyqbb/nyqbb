## 📖 项目简介 / Project Overview

纪元智能（ASI）是一个基于纯符号主义路线的通用语义执行系统。区别于传统的连接主义（大模型概率拟合），我们以自然语言为输入，以显式规则表为指令集，构建了一个内核较小、多样性由外部加载扩展的确定性推演平台。

*ASI is a general-purpose semantic execution system based on the pure symbolic approach. Unlike connectionism (probabilistic fitting of large models), it uses natural language as input and explicit rule tables as instruction sets, building a deterministic reasoning platform with a relatively small kernel and diversity expanded through external loading.*

**长期愿景：从确定性本体出发，向本体智能演进。**

*Long-term vision: starting from a deterministic ontology, evolving toward Ontology Intelligence.*

## 🧭 本体论和超级智能 / Ontology and Superintelligence

**本体论（Ontology）**，在哲学上研究“存在本身”——什么东西真正存在、存在的根本方式是什么。它追问的是：这个世界最底层、最根本的实在是什么。

**本体（the ontological / the fundamental reality）**，就是本体论所追问的那个答案：世界最底层的实在，本宇宙的运行规律。放到本宇宙里，本体是：世界由时空框架与运算层构成；一切变化由时空之间的重叠运算产生；对象同时具有位置尺度属性与变化时序属性，二者不可分离；对象之间的相互作用，本质都是运算。语言只是描述，未触及本体。

*Ontology, in philosophy, studies "being itself"—what truly exists and in what fundamental way. It asks: what is the most fundamental reality of the world? The ontological is the answer to that question: the most fundamental reality, the operating laws of this universe. In this universe, the ontological means: the world consists of a spacetime framework and a computational layer; all change arises from overlapping operations between spacetime; every object carries both spatial-scale attributes and temporal-sequence attributes, inseparable; interactions between objects are, in essence, operations. Language is only description; it does not touch the ontological itself.*

**本体论在先，超级智能在后，是衍生关系。**

*Ontology comes first; superintelligence follows. The relationship is derivation.*

现有主流 AI 路线（如 OpenAI）若没有本体论层面的地基，其功能建立在概率拟合之上，难以获得真实时空坐标、绝对因果与持久状态记忆，长链条推演容易失稳。本项目的路线以本体论为基座：每次运算落在真实状态节点上，每次状态变化可追溯、可复现，记忆为物理级持久化，超级智能才有可验证的地基。

*Existing mainstream AI routes (e.g., OpenAI) without an ontological foundation rest on probabilistic fitting, making it difficult to obtain real spacetime coordinates, absolute causality, and persistent state memory; long-chain reasoning tends to destabilize. This project's route takes ontology as its foundation: every operation lands on real state nodes, every state change is traceable and reproducible, memory is physically persistent, and superintelligence gains a verifiable foundation.*

### ASI L1–L5 分级体系：功能与判定依据 / ASI L1–L5: Functions and Evidence

说明：本分级参照公开的功能分级标准，每一级同时给出“功能描述”和“判定依据”。判定依据不是技术路线说明，而是**可观测、可对比的达成锚点**——凭什么判定系统已处于该级，而不是仅仅宣称。

*Note: This matrix follows publicly available functional-grading standards. Each level provides both a functional description and an evidence basis. The evidence basis is not a technical-route explanation, but an observable, comparable anchor for judging whether the level has been reached—rather than merely claimed.*

- ✔︎ **L1 平台化承载 / Platform Bearing**
  - **功能**：平台可承载任意语义单元与知识模块，领域不设限，支持持续扩展。 / *The platform can carry arbitrary semantic units and knowledge modules, with no domain limit and continuous expansion.*
  - **判定依据**：新增一个此前未接触过的领域模块，无需修改内核代码即可完成加载并执行基础任务；加载前后系统核心代码库无变更。 / *Evidence: A previously unseen domain module can be loaded and execute basic tasks without modifying core code; the core codebase remains unchanged before and after loading.*

- ✔︎ **L2 跨域超人性能 / Cross-Domain Superhuman Performance**
  - **功能**：语言能描述的领域即可接入；确定性执行，速度、精度、可复现性远超人类与主流系统。 / *Any domain describable in language can be connected; deterministic execution with speed, accuracy, and reproducibility far beyond humans and mainstream systems.*
  - **判定依据**：在至少两个互不重叠的领域中，同一输入在多次运行中产出完全一致的结果；完成时间或精度与人类基线或主流系统基线可对比，且优势可重复观测。 / *Evidence: In at least two non-overlapping domains, identical inputs produce identical outputs across repeated runs; completion time or accuracy is comparable to a human or mainstream-system baseline, with the advantage repeatedly observable.*

- ✔︎ **L3 运行时持久改进 / Runtime Persistent Improvement**
  - **功能**：能从执行结果中学习并持续改进，经验跨轮次、跨进程累积。 / *Learns from execution results and improves continuously; experience accumulates across rounds and processes.*
  - **判定依据**：系统在一次运行中处理过的任务类型，在后续独立进程或重启后再次遇到时，无需外部重新配置即可调用先前沉淀的结果或规则；改进后的表现可与改进前记录对比。 / *Evidence: Task types processed in one run can be recalled in subsequent independent processes or after restart without external reconfiguration; post-improvement performance is comparable to pre-improvement records.*

- ✔︎ **L4 环境适应型改进 / Environment-Adaptive Improvement**
  - **功能**：能适应不同说法、不同数据、不同场景，改进方向由反馈决定。 / *Adapts to different phrasings, data, and scenarios; improvement direction is determined by feedback.*
  - **判定依据**：面对同一目标的不同表述、不同数据分布或不同输入格式，系统仍能产出符合预期范围的结果；当外部反馈指向偏差时，后续同类输入的输出分布发生可观测的偏移。 / *Evidence: Different phrasings, data distributions, or input formats of the same goal still yield results within the expected range; when external feedback indicates deviation, the output distribution for subsequent similar inputs shifts observably.*

- ✔︎ **L5 元标准递归修改与受控闭环 / Meta-Standard Recursive Modification and Controlled Closed Loop**
  - **功能**：能修改自身的改进机制本身，形成越改越强的正反馈；按技术路线需要，面向机器人直控设计，为执行更多任务需获取相应的执行权限，适配受控运行环境。 / *Can modify its own improvement mechanisms, forming a self-reinforcing positive feedback loop; as required by the technical route, it is designed for direct robot control, requiring corresponding execution permissions to perform more tasks, and adapted to controlled operating environments.*
  - **判定依据**：系统的改进规则（而非仅任务结果）可被自身触发修改，修改后的新规则在下一次迭代中生效并产生可追溯的变更记录；每一次规则修改的触发条件、变更内容和后续效果均有日志可查。 / *Evidence: The improvement rules themselves (not merely task outputs) can be modified by the system; the modified rules take effect in the next iteration with a traceable change log; every rule modification's trigger, content, and subsequent effect are auditable.*

汇总：L1–L5 全 ✔︎。当前处于 ASI L5 测试阶段；判定依据的验证方式为系统内可观测的运行记录与前后对比，不依赖外部第三方复现。

*Summary: L1–L5 all ✔︎. Currently in ASI L5 testing; the evidence basis is verified through internally observable run records and before/after comparisons, not dependent on external third-party reproduction.*

## ⚙️ 核心技术特征 / Core Features

- **规则驱动为主 / Rule-Driven First**：系统以显式规则为主要执行依据，尽量避免不可控的随机行为，底层逻辑保持可读。 / *The system primarily executes on explicit rules, minimizing uncontrolled randomness and keeping underlying logic readable.*
- **结果可追溯 / Traceable Results**：推演过程保留记录，结果能够回溯到对应的规则与状态，便于回放与核查。 / *Reasoning processes are recorded; results can be traced back to corresponding rules and states for replay and verification.*
- **规则支持热更新 / Hot-Updatable Rules**：规则模块支持版本化管理，可在运行中更新，并保留切换与回退机制。 / *Rule modules support versioned management, can be updated at runtime, with switching and rollback mechanisms.*
- **逻辑与呈现保持一致 / Consistent Logic and Rendering**：符号状态与画面呈现保持对应关系，减少额外适配层。 / *Symbolic states correspond to rendered output, reducing extra adaptation layers.*
- **内核精简，按需扩展 / Minimal Kernel, Modular Expansion**：内核保持精简，扩展能力主要通过外部模块加载实现。 / *The kernel stays minimal; expansion is mainly achieved through external module loading.*
