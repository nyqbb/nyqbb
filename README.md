## 🧠 超级智能 · ASI

| 中文 | English |
|---|---|
| **符号主义路线的通用语义执行系统。** | **A general-purpose semantic execution system on the symbolic AI path.** |
| 区别于依赖海量数据训练、规则隐于权重的主流连接主义方案，ASI 以**显式规则**驱动，将操作系统架构迁移至语言层面：自然语言即输入，规则表即指令集，外部数据即能力来源。ASI 内核保持最小化与稳定化，全部多样性由动态加载的语义单元产生。 | Unlike mainstream connectionist approaches that rely on massive data training with rules buried in weights, ASI is driven by **explicit rules**, migrating the operating system architecture to the language layer: natural language as input, rule tables as instruction sets, external data as the source of capability. The ASI kernel remains minimal and stable, with all diversity emerging from dynamically loaded semantic units. |

**核心特点 / Core Features：**

| 中文 | English |
|---|---|
| **全链路可解释** —— 每次执行均可回溯到具体规则、节点与字段，决策路径透明可查，全流程支持回放与审计，行为可追溯、结果可复现。 | **Full-chain explainability** — Every execution traces back to specific rules, nodes, and fields. Decision paths are transparent and auditable. The entire process supports replay and audit; behavior is traceable and results reproducible. |
| **规则实时更新** —— 规则表与知识数据支持版本化热更新，修改即时生效，无需停机与重训，支持原子切换与失败回滚。 | **Real-time rule updates** — Rule tables and knowledge data support versioned hot updates. Changes take effect immediately without downtime or retraining, with atomic switching and failure rollback. |
| **异常自动转交** —— 未命中或缺失的语义单元不中断执行，自动转交大模型追问补全，核定后写回知识库，后续同类查询直接命中。 | **Automatic exception handoff** — Unmatched or missing semantic units do not interrupt execution. They are automatically handed off to a large model for clarification and completion, then written back to the knowledge base after verification, so subsequent similar queries hit the fast path directly. |
| **跨域平滑扩展** —— 内核保持稳定，加载不同语义模块即可覆盖不同领域，领域迁移不产生重复训练成本，扩展边界由加载能力决定。 | **Smooth cross-domain expansion** — The kernel remains stable. Loading different semantic modules covers different domains, with no retraining cost for domain migration. The expansion boundary is determined by loading capability. |
| **执行评判解耦** —— ASI 专注执行操作、记录后果、维护状态一致性，不内嵌价值判断；权限校验与内容执行分离，行为边界由外部策略定义。 | **Decoupled execution and judgment** — ASI focuses on executing operations, recording consequences, and maintaining state consistency, without embedding value judgments. Permission checks are separated from content execution, and behavioral boundaries are defined by external policy layers. |

**定位 / Positioning：**

| 中文 | English |
|---|---|
| 一个以自然语言为交互接口、以显式规则为执行依据、以动态加载为扩展方式的通用语义执行系统——在保持完全可解释与可审计的前提下，实现能力的持续演进。 | A general-purpose semantic execution system with natural language as its interaction interface, explicit rules as its execution basis, and dynamic loading as its expansion method — achieving continuous capability evolution while remaining fully explainable and auditable. |
